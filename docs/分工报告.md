## 二、邵飞翔的具体工作

1. **数据理解与统计验证**
   - 完成 8.9 GB / 16,545,376 条 CFPB 投诉数据的两次独立流式全量扫描，交叉验证记录数一致；
   - 发现并修正"物理行数（2765 万）≠ 记录数"的问题（叙事字段内嵌换行符）；
   - 产出全量聚合统计（产品/问题/公司/州/年度分布），作为报告图 1、图 2 的数据来源。
2. **解析与抽样模块实现**（`src/parser.py`、`src/sampler.py`）
   - 16 列流式解析、日期格式校验、审计计数器（有效/拒绝及原因）；
   - 产品名历史 schema 归一化（如 `Bank account or service` → `Checking or savings account`）；
   - 蓄水池抽样（O(n) 内存，固定种子）与"先按 ID 排序再洗牌"的确定性划分。
3. **测试 1–7**（`tests/test_parser.py`）：非法日期拒绝、缺列行拒绝、产品名归一化、空叙事接受、州名大写、缺失字段 UNKNOWN 化。
4. **运行时间与可扩展性实测**（报告表 1）：全量扫描 165 s、抽样评估 127 s。

## 三、沈勇的具体工作

1. **基线与评估模块实现**（`src/baseline.py`、`src/evaluate.py`）
   - `RuleBaselineClassifier`（Product→高频 Issue，未见产品回退全局多数类）；
   - `GlobalMajorityBaseline` 对照基线；
   - 准确率 / 宏 F1 / 分类别 P-R-F1 指标自行实现（无第三方评估库，可审查复算）。
2. **测试 8–16**（`tests/test_baseline.py`）：多数类回退、空训练集报错、指标取值域、抽样与划分的种子确定性、端到端冒烟。
3. **基线评估运行与结果分析**：全量抽样（n=200,000，seed=42）下规则基线 acc=0.507 / macro-F1=0.047，多数类基线 0.445 / 0.004；解释宏 F1 偏低源于类别偏斜。
4. **报告图表与报告撰写**：`tools/figures.py` 生成图 1–3；阶段 1 报告（5 页）撰写与排版。
